# Nepali Sentiment Analysis
Learning NLP

## How it works
- Multilingual sentence embeddings (`paraphrase-multilingual-MiniLM-L12-v2`)
- Logistic regression classifier with class balancing
- Trained on 35,789 real Nepali sentences
- Improved neutral class recall from 18% to 53% by addressing class imbalance

## Stack
Python · scikit-learn · sentence-transformers · FastAPI · HuggingFace Spaces
